### [High] Blank maximum-cube input removes the spawn limit

- **File:** `src/gemini3.1-pro/features/cubes-exploding/CubesExplodingScene.js:132`
- **Problem:** Clearing the number input assigns `NaN` to `maxCubes`, so the limit comparison is always false.
- **Evidence:** `parseInt('', 10)` is `NaN`; neither clamp at lines 133–134 applies, and `this.cubes.length >= this.maxCubes` at line 166 is false for `NaN`.
- **Impact:** Users can create unbounded Three.js meshes, exhausting GPU resources and degrading performance.
- **Recommendation:** Require a finite parsed value before clamping and assigning `maxCubes`.

### [High] Gemini's Three.js cube scene has no teardown

- **File:** `src/gemini3.1-pro/features/threejs-cube/ThreejsCubeScene.js:43`
- **Problem:** The scene installs anonymous pointer and resize handlers and recursively schedules animation frames without a `dispose()` method.
- **Evidence:** The resize handler at line 59 cannot be removed by reference, and the frame scheduled at line 71 is never cancelled.
- **Impact:** Remounting leaves active render loops, window listeners, and renderer resources behind.
- **Recommendation:** Store handler references and frame IDs, then implement teardown that removes listeners, cancels frames, and disposes renderer resources.

### [High] Gemini exploding-cube resources persist after removal and teardown

- **File:** `src/gemini3.1-pro/features/cubes-exploding/CubesExplodingScene.js:246`
- **Problem:** Removed meshes and particles are detached but not disposed; teardown also leaves the scheduled animation frame active.
- **Evidence:** Collision cleanup removes cubes at lines 247–248 without disposing their geometry or material, while `dispose()` at line 282 does not cancel the frame scheduled at line 256 or release remaining scene objects.
- **Impact:** Repeated collisions and remounts leak CPU and GPU resources.
- **Recommendation:** Cancel the animation frame and explicitly dispose meshes, geometries, materials, and particles on removal and teardown.

### [Medium] Coordinate-system cube renders as a flat square
